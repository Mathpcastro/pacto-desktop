# O objetivo

O carrossel não termina no último card. Ele gera uma ação que abre caminho para a oferta.

# Fluxo principal

<b>Carrossel → CTA → Comentário → DM → Entrega → Oferta</b>

## 1. Carrossel

Entregue valor real antes de pedir algo.

## 2. CTA

Use uma palavra-chave simples e relacionada ao conteúdo.

Exemplo: “Comente PROMPT para receber o material.”

## 3. Comentário

O comentário gera engajamento e identifica alguém interessado naquele assunto.

## 4. DM

Uma automação pode responder e entregar o material prometido.

## 5. Entrega

Entregue primeiro exatamente o que foi prometido. Pode ser prompt, checklist, guia, template, recurso, aula ou outro material útil.

## 6. Oferta

Depois da entrega, conecte naturalmente o material ao que você vende.

# Modelo simples de DM

```txt
Mensagem 1
Aqui está o material que prometi: [LINK/ENTREGA]

Mensagem 2
Se você quiser ir além e resolver [PROBLEMA MAIOR], eu criei [PRODUTO], que [BENEFÍCIO PRINCIPAL].
[LINK DA OFERTA]
```

# Exemplos de conexão

## Curso

Carrossel entrega uma técnica → DM entrega checklist → oferta apresenta o treinamento completo.

## SaaS

Carrossel entrega ferramenta/processo → DM entrega recurso → oferta apresenta o software que simplifica ou automatiza o processo.

## Serviço

Carrossel entrega diagnóstico ou passo a passo → DM entrega material → oferta convida para conhecer o serviço.

# Prompt — CTA + Entrega + Oferta

```txt
Com base no carrossel abaixo e no produto que eu vendo, crie uma estratégia simples de conversão por comentário e DM.

PRODUTO:
[DESCREVA]

CARROSSEL:
[COLE]

Crie:
1. 10 palavras-chave de CTA fáceis de comentar.
2. Uma frase curta de CTA para o primeiro card.
3. Um CTA para o último card.
4. Uma ideia de material gratuito coerente com a promessa do carrossel.
5. Uma primeira mensagem de DM que entrega o prometido sem enrolação.
6. Uma segunda mensagem que conecta o material ao produto sem parecer propaganda forçada.

Regras:
- O material gratuito precisa ser realmente útil.
- Não esconda a entrega atrás da oferta.
- A pessoa deve receber primeiro aquilo que foi prometido.
- A oferta precisa ser uma continuação lógica do conteúdo.
- Linguagem curta, simples e natural.
```

# O último card como peça de conversão

Os exemplos analisados mostram que o melhor último card não funciona como rodapé. Ele funciona como <b>uma mini landing page dentro do carrossel</b>.

Ele precisa responder rapidamente:

1. O que eu ganho?
2. O que exatamente vou receber?
3. O que preciso fazer agora?

## Estrutura recomendada

<b>Headline de desejo</b>

Quer \[resultado\]?

<b>Entregável concreto</b>

Eu organizei \[guia/prompts/links/plugins/skills/projeto\] para você.

<b>Ação única</b>

Comente \[PALAVRA\] para receber na DM.

# Prompt — CTA final baseado no conteúdo

```txt
Leia este carrossel e crie um último card que funcione como uma mini página de conversão.

Sua tarefa é encontrar a continuação mais natural do conteúdo.

O último card precisa:
- reafirmar o principal resultado desejado
- dizer exatamente o que será entregue
- usar uma única palavra-chave de comentário
- ser curto e visualmente simples
- não depender da legenda para fazer sentido
- não adicionar uma promessa desconectada do conteúdo

CARROSSEL:
[COLE]

PRODUTO:
[DESCREVA]

MATERIAL DISPONÍVEL PARA ENTREGAR:
[DESCREVA]

Crie 5 opções com:
1. headline
2. linha de apoio
3. CTA
4. palavra-chave sugerida
5. ideia visual para o card
```

# Regra do entregável

Quanto mais tangível o material, melhor.

Prefira:

- “guia com links e comandos” a “mais informações”
- “8 prompts completos” a “conteúdo extra”
- “projeto + prompt de instalação” a “tutorial”
- “6 skills prontas para instalar” a “lista de recursos”

<b>O aluno precisa saber exatamente o que chega na DM antes de comentar.</b>
