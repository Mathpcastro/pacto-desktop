# Como adaptar um hook

Não use o hook vazio. Complete com contexto específico.

<b>Fraco:</b> “Antes de fazer X, veja isso.”

<b>Melhor:</b> “Antes de contratar mais um designer para seu SaaS, veja isso.”

<b>Fraco:</b> “A internet errou nessa aqui.”

<b>Melhor:</b> “A internet errou quando disse que você precisa postar menos e caprichar mais.”

<b>Fraco:</b> “O código secreto para \[objetivo\].”

<b>Melhor:</b> “O código secreto para transformar comentário em venda sem mandar DM manual.”

```txt
CONTEXTO

Público: [DESCREVA]
Problema principal: [DESCREVA]
Desejo principal: [DESCREVA]
Assunto do carrossel: [DESCREVA]

HOOK-BASE:
[COLE]

Crie 10 versões.

Regras:
- preserve o mecanismo de atenção do hook
- torne a promessa específica
- use linguagem natural
- evite clickbait sem entrega
- prefira frases que possam ser entendidas em 2 segundos
- se possível, use número, prazo, ferramenta, erro ou resultado concreto
- não use linguagem corporativa
- não repita a mesma construção 10 vezes

Depois escolha as 3 mais fortes e explique em uma frase por que cada uma tem potencial.
```

# CTAs recomendados para o método Carrossel que Vende

No curso, priorize CTA por <b>palavra-chave</b>, porque ele é mais fácil de automatizar e conecta conteúdo a DM.

Exemplos:

- Comente <b>PROMPT</b> para receber o modelo.
- Comente <b>GUIA</b> para receber o passo a passo.
- Comente <b>CHECKLIST</b> para receber a lista completa.
- Comente <b>AULA</b> para receber o material.
- Comente <b>MAPA</b> para receber a estrutura.
- Comente <b>MODELO</b> para receber o template.

<callout icon="🎯" color="orange_bg">
O CTA deve entregar algo coerente com o carrossel. <b>Primeiro entregue o prometido. Depois conecte à oferta.</b>
</callout>

# Prompt — Gerador de CTA por palavra-chave

```txt
Com base no carrossel abaixo, crie 10 CTAs por palavra-chave.

CARROSSEL:
[COLE]

PRODUTO QUE EU VENDO:
[DESCREVA]

Crie para cada opção:
1. palavra-chave curta
2. CTA para o primeiro card
3. CTA para o último card
4. o que será entregue na DM
5. ponte natural entre a entrega e o produto

Regras:
- palavra-chave fácil de digitar
- não usar frases longas
- a entrega deve ser relevante para o carrossel
- não prometer algo que não será entregue
- priorizar utilidade real
- a oferta entra depois da entrega
```
